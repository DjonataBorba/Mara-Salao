# 💇‍♀️ Mara Cantinho da Beleza

Landing page responsiva e elegante desenvolvida para um salão de beleza, focada na conversão de clientes e na facilidade de agendamento de serviços.

## 🚀 Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 Avançado (Flexbox, Mobile-First, Position Sticky, Backdrop Filter)
- JavaScript Vanilla (Manipulação de DOM, Métodos de Array, LocalStorage)

## 💡 Recursos Implementados
- **Menu Fixo Moderno:** Barra de navegação com efeito blur que acompanha a rolagem da tela.
- **Persistência com LocalStorage:** Os agendamentos feitos ficam salvos no navegador do usuário.
- **Controle de Acesso:** Função de exclusão de agendamentos protegida por validação de senha no JavaScript, simulando uma regra de negócio administrativa.
- **Integração WhatsApp:** Disparo de mensagens automáticas com os dados do serviço e horário escolhidos.
